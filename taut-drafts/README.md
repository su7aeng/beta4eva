# taut-drafts

매일 아침 07:00(KST) 데일리 리서치 루틴이 카드뉴스 초안을 여기에 커밋한다.
파일명은 `YYYY-MM-DD.md`.

각 파일에 담기는 것:
- 그날 만든 초안 2편 (카드 6~8장씩, 캡션·해시태그 포함)
- 카드별 출처
- **확인 필요** 목록 — 출처가 한 곳뿐이거나 상충하는 것. 카드로 만들기 전에 사람이 봐야 한다
- 다음 편 후보

## 초안에서 카드로

초안이 그대로 발행되지는 않는다. `확인 필요`를 먼저 해소하고,
`~/taut-research/cards_data.py` 에 편을 추가한 뒤 `make_cards.py` 를 돌리고,
`taut/index.html` 에 붙여 배포한다.

## 발행 형태 — 둘 다 유지한다

카드는 **B(인쇄 매거진)와 C(스펙 시트) 두 형태**로 낸다. 하나를 고르지 않는다.
`make_cards.py` 한 번이면 `cards/B`, `cards/C` 에 전량이 나온다.
사이트에는 상단 전환 스위치가 붙어 있다.

새 편을 추가하거나 디자인을 고칠 때는 **매번 두 방향을 전량 다시 뽑는다.**
표지 몇 장만 보면 본문·흐름·글 긴 카드에서 깨지는 걸 못 잡는다.

공통 규칙: 색 면으로 강조하지 않는다. 기본 줄은 Light/Regular,
강조 줄만 Medium/Bold — 강조는 굵기로 한다.

## 규칙

공개 저장소다. 원가·마진·소싱처·알리바바 링크는 여기에 적지 않는다.
